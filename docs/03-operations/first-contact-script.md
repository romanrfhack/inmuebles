# Guion de primer contacto

## Mensaje inicial WhatsApp
Hola, gracias por contactar a Patrimonio Claro. Recibimos su solicitud y queremos entender mejor su caso para realizar una revisión inicial. Esta revisión no implica contratación y cada asunto requiere análisis individual antes de canalizarse con el especialista.

## Preguntas mínimas
- ¿En qué ciudad o municipio está el inmueble?
- ¿El inmueble está a su nombre, heredado, comprado o en posesión?
- ¿Cuenta con escrituras o algún documento?
- ¿Cuál es el problema principal que quiere resolver?
- ¿Busca vender, comprar, escriturar, heredar o regularizar?
- ¿Tiene urgencia o fecha límite?

## Mensaje si el caso es viable
Gracias por la información. Con lo que nos comparte, el caso parece tener elementos para una revisión más formal. Prepararemos un resumen preliminar para que el especialista lo revise y podamos indicarle el siguiente paso.

## Mensaje si falta información
Gracias. Para poder orientar mejor la revisión inicial, necesitamos algunos datos adicionales antes de avanzar. En cuanto nos comparta esa información, continuamos con la valoración preliminar.

## Mensaje si no parece viable
Gracias por compartirnos su caso. Por ahora no vemos elementos suficientes para avanzar a una revisión especializada dentro del alcance actual de Patrimonio Claro. Si más adelante cuenta con información adicional o cambia el contexto del asunto, podemos revisarlo nuevamente.
