# Prompts Log

## Propósito
Registrar prompts relevantes usados para coordinar, definir o construir el proyecto, de forma que exista trazabilidad de cómo se tomaron decisiones y se produjeron entregables.

## Convención sugerida
Para cada prompt registrar:
- fecha
- objetivo
- prompt o resumen del prompt
- resultado esperado
- archivos afectados

- Resultado esperado: Repositorio listo para trabajar por fases sin arrancar aún desarrollo funcional.
- Archivos afectados: carpeta docs y documentos base del proyecto.
